# 🎮 Jogo da Velha em Python

## 📌 Objetivo
Desenvolver um jogo da velha utilizando Python, praticando conceitos de lógica de programação.

## 🛠️ Tecnologias utilizadas
- Python
- Listas
- Funções
- Estruturas condicionais
- Estruturas de repetição

## 👨‍💻 Contribuição
Projeto desenvolvido individualmente durante meus estudos de Análise e Desenvolvimento de Sistemas (ADS).

## 📸 Evidências
O projeto possui um arquivo Python chamado `jogo_da_velha.py`, contendo o código-fonte do jogo.

## 🚀 Como executar
1. Instale o Python.
2. Baixe o arquivo `jogo_da_velha.py`.
3. Abra o terminal na pasta do projeto.
4. Execute:

python jogo_da_velha.py
